User Interaction

Describe how a user interacts with the feature step by step. Explain what JavaScript changes on the page after the user clicks, selects, or enters information.

Include the key action and the visible result.

Response:

    Users interact with the feature by clicking the “Save as Favorite” button under any course.

     When clicked, JavaScript stores the class name in on-device storage and instantly spotlights the selected class with a green border and soft background color. All other classes return to their default state, making the favorite visually clear. When the repeat visitor comes back to the page later, the saved favorite load programmatically and rendered illuminated again.

 

 

 

 

Form Validation

Identify at least two JavaScript validation checks you added to your form. Explain how invalid submission is prevented and how feedback appears near the relevant fields so users can correct their entries.

Reference Screenshot 2 and quote or summarize at least one error message.

Response:

 

     I added two JavaScript validation checks to the workshop inquiry form: a minimum length check for the full name and an email pattern matching using a regular expression. If the user enters an invalid name or email, the form prevents submission and displays error messages such as “please enter a valid name” and “doubled-check your email address” directly under the fields. These messages help users fix errors without losing any information they already typed.

 

 

 

 

Data Storage

State whether you used localStorage or sessionStorage. Explain what data is stored, when it is saved, and when it is loaded again. Describe how this improves the user experience.

Reference Screenshot 3 and identify the restored or remembered data.

Response:

     I used localStorage to save two pieces of data: the user’s preferred class and the submitted email they type into the form. The favorite class is saved when the user hits the button to confirm, and the email saves as you type. When the page leads again, JavaScript retrieves the saved progress and autofill them, either by highlighting the saved class or pre-filling the email field. This improves the user experience by remembering their saved defaults and reducing re-keying.

Client Alignment:

     My design choices support Riverbend Yoga Studio’s grounded, welcoming, and empathetic. Because the studio’s audience includes newcomers, busy professionals, and mature adults, I prioritized clarity, restful, and breathable that reduce visual clutter.

     For example, the homepage “Feature Class” Rhythmic, subtle, and scannable help guide users through the content without overwhelming them. The CSS emphasizes a tranquil that mirrors the studio’s mission of creating an inviting for all experience levels.

Color Palette:

     I used a palette of soft green (#7BAE7F), warm beige (#F5F1E8), deep charcoal (#333333), and white (#FFFFFF). These colors reinforce equanimity and affability while maintaining strong contrast for legibility. Green evokes biophilic and repose, while the beige provides a cordial, anchored background that feels inviting to newcomers and mature adults. For instance, the navigation bar uses charcoal text on a beige background to ensure sharp differentiation and glanceability.

Typography:

     I selected Lato for body text and Merriweather for headings. Lato’s cleans humanist improves readability on both compact viewpoint and expansive canvas, while Merriweather’s soft-bracketed adds a sense of unflappability. For example, section heading Merriweather in an amplified, heavyweight to help users quickly identify key content areas while scanning and reduce mental overhead.

Responsive Design:

     The layout uses a mobile-first approach with Flexbox to streamlines, curates, and segments. A media query at 768px adjusts spatial rhythm, inline reflow, and side-by-side reflow. For instance, the “Classes and Services” page shifts from a singular axis on mobile to a dual-track grid Flexbox layout on tablets and desktops, improving optical equilibrium without compromising legibility.

Design Challenge:

     One challenge was balancing serene visuals with sufficient contrast for universal usability. Softer colors risk becoming too subtle, especially for mature adults. I addressed this by pairing alabaster canvas with graphite typography and ensuring buttons use resonant verdant. This preserved the studio’s soothing while meeting diverse abilities.
